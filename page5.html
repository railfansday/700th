The Overview tab in the dashboard now lets you choose which metric appears on each project card.

Project cards used to show a fixed Real Experience Score in the top right, but not everyone on your team watches the same signal. Available widgets

  • Firewall: allowed requests, denied requests

Pick per project

Open the switcher in the top right of any project card. The menu shows the current value for each available metric. When you select one, your choice is saved for that project and follows your account across refreshes and devices.

Enable features from the card

If a project does not have a feature enabled, you can start the enable flow from the widget menu without leaving the Overview tab. This is available for Speed Insights Plus, Web Analytics, and alerts.

#34805. Create custom monitors in Vercel Observability

📅 27 Oct 2026 | Category: other | Source

You can now create custom monitors to get alerts based on your Vercel Observability query results.

For example, you can track signals such as AI Gateway costs, Core Web Vitals and other performance metrics, Workflow and external API failure rates, or Vercel Sandbox CPU time.

Each monitor tracks a single metric, such as response time, or a ratio of two metrics, such as errors divided by total requests. Choose statistical anomaly detection or a fixed threshold, then configure the detection window, filters, and grouping.

To create a monitor, inspect a chart’s query in Observability, start from a preset, or open Settings > Alerts for your team.

You can also define a custom monitor in a JSON file and create it with vercel monitors add in the Vercel CLI. Run vercel monitors schema --type custom for the schema and examples.

Receive alerts through email, Slack, Vercel Inbox, push notifications, or team-level webhooks. You can also add context for Vercel Agent to use when investigating an alert.

Custom monitors are available on Pro and Enterprise plans with Observability Plus, at $0.0035 per GB of data scanned. Built-in alerts remain included with Observability Plus.

Create a custom monitor or learn more in the configuration documentation.

#35522. Pemerintah komitmen perluas akses pendidikan

📅 27 Oct 2026 | Category: technology | Source

Jakarta (ANTARA) - Kepala Badan Komunikasi Pemerintah (Bakom) RI Syahganda Nainggolan menegaskan pemerintah berkomitmen memperluas akses pendidikan dengan ketersediaan infrastruktur, selain program pembelajaran di sekolah.

"Pemerintah sudah bekerja keras, termasuk Kementerian Pendidikan Dasar dan Menengah, tetapi berbagai upaya tersebut belum terkomunikasikan dengan baik kepada masyarakat," ujar Syahganda dalam keterangan di Jakarta, Selasa.

Menurutnya, berbagai upaya yang dilakukan pemerintah perlu dipahami secara utuh oleh masyarakat, mulai dari peningkatan kualitas pembelajaran, penguatan peran guru, hingga pembangunan infrastruktur yang memudahkan anak-anak menjangkau sekolah.

Keberhasilan pembangunan pendidikan tidak hanya ditentukan oleh program yang berlangsung di ruang kelas, tetapi juga oleh kemampuan pemerintah mengatasi hambatan yang dihadapi masyarakat untuk memperoleh pendidikan, terutama di daerah terpencil.

Ia menilai salah satu bentuk nyata komitmen pemerintah terhadap pemerataan pendidikan terlihat dari upaya memperluas akses pembelajaran hingga ke desa-desa.

Baca juga: Mendikdasmen jelaskan kendala penyaluran dana PIP respons temuan BPK

Program digitalisasi pendidikan dan penguatan peran guru menjadi bagian dari langkah tersebut, sehingga layanan pendidikan diharapkan dapat menjangkau masyarakat secara lebih luas.

Namun, pemerataan pendidikan tidak cukup hanya dengan menghadirkan program pembelajaran dan tenaga pendidik.

Infrastruktur yang memadai juga menjadi kebutuhan mendasar, terutama bagi anak-anak yang tinggal di wilayah dengan kondisi geografis sulit.

"Sebagai contoh, pembangunan jembatan-jembatan yang menghubungkan desa-desa terpencil yang sebelumnya terpisah oleh sungai. Dengan adanya jembatan tersebut, masyarakat, khususnya anak-anak, kini dapat bersekolah dengan lebih mudah," katanya.

Menurutnya, pembangunan infrastruktur pendidikan membutuhkan kolaborasi lintas kementerian. Dukungan terhadap sarana dan prasarana harus berjalan beriringan dengan kebijakan peningkatan kualitas pembelajaran agar manfaat pembangunan dapat dirasakan langsung oleh masyarakat.

Baca juga: Seskab: Presiden terima laporan progres pendidikan kepemimpinan URI

Pendekatan tersebut menunjukkan bahwa pembangunan pendidikan merupakan pekerjaan bersama.

Selain akses sekolah, Syahganda juga menyoroti pentingnya perhatian terhadap kesejahteraan guru.

Menurutnya, dukungan pemerintah melalui tunjangan dan berbagai bantuan bagi guru, merupakan bagian penting dari upaya memperkuat sektor pendidikan.

"Perhatian pemerintah terhadap nasib guru selama ini begitu luar biasa, baik melalui pemberian tunjangan maupun berbagai bantuan lainnya. Perhatian tersebut diberikan kepada guru yang sudah tercatat sebagai aparatur sipil negara (ASN) maupun yang belum tercatat sebagai ASN," ucap Syahganda.

Dia meyakini pendidikan bermutu menjadi salah satu jalan bagi masyarakat untuk meningkatkan taraf hidup.
